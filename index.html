Claude Code работает на облачной виртуальной машине с вашим репозиторием: пишет код, запускает тесты, проверяет в браузере и пушит в GitHub. Сессия продолжается, даже если вы закрыли ноутбук, а следить за ней можно с любого устройства.

Терминал и облако

Шпаргалка команд

Нужен Claude Code CLI, вошедший в тот же аккаунт claude.ai. Облачная машина клонирует ваш репозиторий с GitHub на текущей ветке, поэтому локальные коммиты сначала запушьте.

Отправить задачу в облако
claude --cloud "Почини баг авторизации в src/auth/login.ts"

Создаёт новую облачную сессию, а вы продолжаете работать локально. Старое написание --remote тоже работает.

Несколько задач параллельно
claude --cloud "Почини нестабильный тест auth.spec.ts"
claude --cloud "Обнови документацию API"

Каждая команда запускает отдельную независимую сессию.

Дописать в идущую сессию
claude -p "Теперь добавь тесты" --cloud <session-id>

Ставит сообщение в очередь сессии и сразу завершается. Подходит для скриптов и CI. Вместо ID можно передать ссылку claude.ai/code/…

Забрать сессию в терминал
claude --teleport

Подтягивает ветку и всю историю разговора. Внутри CLI: /teleport или /tp, а в /tasks клавиша t. Перенос односторонний: из облака в терминал.

Сначала план, потом облако
claude --permission-mode plan

Обсудите план локально, сохраните его в репозиторий и запушьте, затем отдайте выполнение в облако: claude --cloud "Выполни план из docs/plan.md".

Репозиторий не на GitHub
CCR_FORCE_BUNDLE=1 claude --cloud "Прогони тесты"

Загружает локальный репозиторий архивом до 100 МБ вместе с незакоммиченными изменениями. Файлы вроде .env и ключей не уходят. Запушить обратно в GitLab или Bitbucket сессия не сможет.

Облачное окружение

Сеть, переменные и setup-скрипт

Окружение — это сохранённая конфигурация, в которой запускаются сессии. По умолчанию создаётся окружение Default с уровнем сети Trusted и без дополнительных настроек.

Уровни сетевого доступа

NoneСеть закрыта.
TrustedТолько белый список: реестры пакетов, GitHub, облачные SDK. Уровень по умолчанию.
FullЛюбые домены.
CustomСвой список доменов, по желанию плюс стандартный.

При любом уровне доступны GitHub (через отдельный прокси), включённые коннекторы (их трафик идёт через серверы Anthropic) и API Anthropic. Новый уровень применяется к уже идущим сессиям примерно за минуту.

Переменные окружения

Задаются в настройках окружения. Их видит каждый, кто пользуется окружением, поэтому секреты туда не кладут. Так же меняются таймауты команд: BASH_DEFAULT_TIMEOUT_MS, BASH_MAX_TIMEOUT_MS.

Сетевые секреты

API-ключ хранится вне машины. Прокси Anthropic добавляет его к запросам на указанные хосты уже после того, как запрос покинул машину. Claude пользуется API, не видя ключа.

Setup-скрипт

Bash от root перед запуском Claude: apt install, тулчейны, docker compose pull. Должен завершиться с кодом 0. Если уложился примерно в 5 минут, файловая система кэшируется, и следующие сессии стартуют сразу. Кэш живёт около 7 дней.

SessionStart-хук

Хранится в .claude/settings.json репозитория и запускается при каждом старте сессии, локально и в облаке. Подходит для npm install и подготовки проекта.

GitHub

Ветки, PR и авто-фикс

Подключить GitHub можно двумя способами: через Claude GitHub App при онбординге или командой /web-setup из терминала, которая передаёт токен локального gh.

GitHub-прокси

  • Ваш настоящий токен никогда не попадает в машину: прокси подставляет его на своей стороне.
  • Нельзя удалять ветки и пушить теги, только ветки.
  • API доступен только для репозиториев, подключённых к сессии.
  • GraphQL закрыт, вместо него REST: gh api repos/…

Авто-фикс пулл-реквестов

  • Claude подписывается на события PR: упавший CI и комментарии ревьюеров.
  • Если исправление очевидно, сам его пушит. Если неоднозначно, спрашивает вас.
  • Включается в меню PR в карточке Changes, командой /autofix-pr или просьбой «следи за этим PR».
  • Нужен установленный Claude GitHub App.

Ревью изменений

  • Карточка Changes показывает +/− строк и открывает дифф.
  • Комментарии к строкам уходят Claude вместе со следующим сообщением.
  • Сравнение с любой веткой через Compare against.

Ссылка на сессию

  • Коммиты получают трейлер Claude-Session: <url>.
  • В описание PR добавляется ссылка на сессию.
  • Отключается настройкой attribution.sessionUrl: false.
Работа с сессиями

Управление, контекст и шаринг

Режимы прав

Режим выбирается в выпадающем списке при создании задачи и меняется прямо во время работы. После перезапуска машины сессия продолжает в том же режиме.

Контекст

/compact сжимает разговор, /context показывает содержимое окна, /clear начинает с чистого листа. При заполнении окна сжатие срабатывает автоматически.

Команды

/model sonnet, /effort, /rename принимают значение аргументом. /fast включает быстрый режим. Чисто терминальные /plugin и /resume недоступны.

Субагенты и команды агентов

Субагенты работают так же, как локально, а агенты из .claude/agents/ подхватываются сами. Команды агентов включаются переменной CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=1.

Очередь сообщений

Пока Claude работает, новое сообщение ждёт в очереди. Его можно забрать крестиком и отредактировать, пока Claude его не прочитал.

Шаринг, архив, удаление

Team и Enterprise делятся с командой, Pro и Max публикуют для любого вошедшего пользователя. Архив убирает сессию из списка, удаление стирает навсегда.

Автоматизация

Claude работает, пока вас нет

Задачи по расписанию

Промпт, репозитории и коннекторы, упакованные один раз. Запускаются по расписанию, HTTP-запросом с токеном или по событию GitHub, например при новом PR или релизе. Создаются на claude.ai/code/routines или командой /schedule.

Проекты

Один разговор, в котором Claude сам запускает параллельные облачные сессии по вашим репозиториям, следит за ними и отчитывается.

Remote Control

Обратная сторона: локальная сессия на вашем компьютере, которой можно управлять с телефона или из браузера. Подходит, когда нужны локальные файлы или мощное железо.

Ultrareview

Глубокое ревью кода несколькими агентами в облачной песочнице.

Напоминания себе

Claude может запланировать, когда вернуться к работе в этой же сессии: перепроверить CI, дождаться деплоя, продолжить после паузы.

Claude Tag в Slack

@Claude в каналах Slack. Сессии из Slack автоматически видны команде.

Что переносится из вашей настройки

Работает всё, что закоммичено

Сессия стартует со свежего клона, поэтому всё, что лежит только на вашем компьютере, в облако не попадает. Нужные настройки коммитьте в репозиторий.

Доступно в облаке

  • CLAUDE.md и .claude/rules/ репозитория
  • Хуки и права из .claude/settings.json
  • MCP-серверы из .mcp.json
  • .claude/skills/, agents/, commands/
  • Навыки, включённые на claude.ai
  • Настройки организации

Остаётся на компьютере

  • Личный ~/.claude/CLAUDE.md
  • Личные skills, agents и commands из ~/.claude/
  • Плагины из пользовательских настроек
  • MCP-серверы, добавленные без --scope project
  • Интерактивный вход вроде AWS SSO
Железо и время

Ресурсы и лимиты

4vCPUдля сборок, тестов и серверов
16ГБ RAMхватит на базу, бэкенд и браузер разом
30ГБ дискапространство на одну сессию
Команды

Claude ждёт команду 2 минуты, может попросить до 10. Не уложившаяся команда уходит в фон и работает ещё до 30 минут.

Setup

Скрипт кэшируется, только если уложился примерно в 5 минут.

Хуки

SessionStart-хук прерывается через 600 секунд, если не задан свой таймаут.

Простой

Через несколько минут без активности машина засыпает с сохранёнными файлами, потом её могут освободить. При повторном открытии история разговора восстанавливается, а фоновые процессы нет.

Безопасность

Изоляция по слоям

Отдельная машина

Каждая сессия работает в изолированной виртуальной машине, отделённой от вашего компьютера и от других сессий.

Контроль сети

Весь исходящий трафик идёт через прокси с защитой от вредных запросов и ограничением частоты. Сеть можно закрыть полностью.

Ключи вне песочницы

Git-учётные данные, ключи подписи и сетевые секреты не попадают в машину: прокси подставляет их снаружи.

Даже при уровне сети None Claude Code общается с API Anthropic, поэтому данные теоретически могут покинуть машину этим путём.

Лимиты

Облачные сессии делят лимиты со всем остальным использованием Claude. Параллельные задачи расходуют их быстрее.

Платформа

Клонирование и PR работают только с GitHub, включая GitHub Enterprise Server на Team и Enterprise.

Организации

С Zero Data Retention, HIPAA или собственными ключами шифрования (CMEK) облачные сессии недоступны. С IP-allowlist нужно исключение от поддержки.

Временность

Машина одноразовая. Остаётся только то, что запушено в GitHub. Запущенный сервер снаружи не виден, для публичной ссылки нужен деплой.
