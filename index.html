Возможности

Полный стек в одном контейнере

Всё нужное уже установлено. Claude сам ставит пакеты, поднимает сервисы и проверяет результат.

Фронтенд

Страницы, приложения на React и Vue, сборка через Vite. Вёрстка проверяется на десктопе и на телефоне.

HTML/CSSReactVite

Бэкенд

API на Express, FastAPI или Go. Сервер запускается прямо в контейнере, и Claude дёргает его запросами.

NodePythonGoRust

Базы данных

Локальные PostgreSQL и Redis для разработки: схемы, миграции, запросы и тесты на живой базе.

PostgreSQL 16Redis 7SQLite

Свой браузер

Chromium с Playwright: Claude открывает ваше приложение, кликает по кнопкам и присылает скриншоты.

ChromiumPlaywright

Git и GitHub

Коммиты и пуш в рабочую ветку, пулл-реквесты по просьбе. Может следить за CI и отвечать на ревью.

commitpushPRCI

Публикация

Страница уходит приватной ссылкой на claude.ai, а через подключённый Vercel можно задеплоить проект на публичный адрес.

ArtifactVercel
Как это работает

От сообщения до пуша

Вы пишете задачу

Из браузера, приложения или с телефона. Обычным языком.

Контейнер стартует

Свежий клон репозитория в изолированной песочнице.

Claude работает

Читает код, пишет файлы, запускает команды и тесты.

Проверка

Тесты, линтер, скриншоты в браузере. Сначала доказать, потом пушить.

Пуш в ветку

Изменения в GitHub, а по просьбе ещё и пулл-реквест.

Железо и границы

Что внутри и чего ждать

4ядрадля сборок, тестов и серверов
15ГБ RAMхватит на базу, бэкенд и браузер разом
8языковNode, Python, Go, Rust, Java, Ruby, PHP, Bash
Временно

Контейнер удаляется после сессии. Остаётся только то, что запушено в GitHub.

Изолировано

Запущенный сервер виден только внутри контейнера. Чтобы открыть его по ссылке, нужен деплой, например на Vercel.

Локальная БД

Postgres в контейнере подходит для разработки и тестов. Для постоянных данных нужна внешняя база: Neon, Supabase или Vercel Postgres.

Сеть

Выход в интернет идёт через прокси и зависит от сетевой политики окружения.
