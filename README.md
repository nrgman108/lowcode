# lowcode

Тестовый проект для проверки Claude Code в облаке.

## Что внутри

Одностраничный справочник по облачному режиму Claude Code: где запускать, возможности, типовые сценарии, шпаргалка команд терминала, облачные окружения и сеть, установленные инструменты, GitHub и авто-фикс PR, работа с сессиями, автоматизация, что переносится из локальной настройки, лимиты, безопасность и тарифы. Факты взяты из документации https://code.claude.com/docs/en/claude-code-on-the-web.

Оформление:

- анимированное «северное сияние» на фоне и стеклянные панели;
- терминал, в котором печатается пример сессии;
- бегущая лента технологий;
- карточки сценариев с цветными метками по типу запуска;
- карточки с подсветкой за курсором;
- липкая навигация с подсветкой текущего раздела и полоса прогресса чтения;
- кнопки копирования у команд;
- светлая и тёмная темы, поддержка `prefers-reduced-motion`.

Сборка через [Vite](https://vite.dev), шрифты из Google Fonts.

## Структура

```
index.html        точка входа Vite: разметка страницы
src/main.js       поведение: терминал, подсветка карточек, навигация, прогресс, копирование
src/styles.css    стили: токены цветов и шрифтов, темы, анимации, адаптив
vite.config.js    настройки dev-сервера и сборки
```

## Запуск

Нужен Node.js 20.19+ или 22.12+.

```bash
npm install
```

```bash
npm run dev
```

Dev-сервер с горячей перезагрузкой: http://localhost:5173

```bash
npm run build
```

Production-сборка в папку `dist/`.

```bash
npm run preview
```

Локальный просмотр собранной версии: http://localhost:4173
