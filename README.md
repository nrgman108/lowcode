# lowcode

Тестовый проект для проверки Claude Code в облаке.

## Что внутри

`index.html` — одностраничный лендинг о возможностях облачного режима Claude Code:

- анимированное «северное сияние» на фоне и стеклянные панели;
- терминал, в котором печатается пример сессии;
- бегущая лента технологий;
- карточки с подсветкой за курсором;
- светлая и тёмная темы, поддержка `prefers-reduced-motion`.

Зависимостей нет, только шрифты из Google Fonts.

## Как открыть

Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python3 -m http.server 8000
```

и перейдите на http://localhost:8000.
